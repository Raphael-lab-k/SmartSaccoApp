# SmartSacco App 🏦

**SmartSacco** is a modern, feature-rich Android application designed to digitize and streamline Savings and Credit Co-operative (Sacco) operations. It combines traditional micro-finance principles with social finance features like community vouching and collective saving pots.

## 🚀 Key Features

*   **Smart Loan Management**: 
    *   Dynamic risk assessment based on balance, trust scores, and KYC status.
    *   Instant auto-approval for low-risk applications.
    *   Detailed repayment tracking and history.
*   **Social Trust System**: 
    *   Members can **vouch** for each other to boost trust scores.
    *   Higher trust scores unlock better loan limits and lower risk levels.
*   **Collective Saving Pots**: 
    *   Create targeted savings goals (e.g., "Land Purchase", "Emergency Fund").
    *   Contribute individually or as a group with real-time progress tracking.
*   **Digital Marketplace**: 
    *   An integrated platform for members to list and purchase items.
    *   Escrow-style transaction handling for increased security.
*   **Secure Banking Operations**: 
    *   Digital deposits, withdrawals, and peer-to-peer fund transfers.
    *   Biometric authentication support for secure access.
*   **Admin Power Tools**: 
    *   Comprehensive dashboard for member KYC verification and loan approvals.
    *   Full audit logging for every transaction and sensitive action.
    *   PDF statement generation for financial reporting.

## 🛠 Tech Stack

*   **Language**: Kotlin & Java (Modern mixed-language architecture)
*   **UI Framework**: Material Design 3 with View Binding
*   **Architecture**: MVVM with Clean Architecture principles
*   **Dependency Injection**: Hilt (Dagger)
*   **Local Database**: Room Persistence Library
*   **Backend & Sync**: 
    *   **Firebase Auth**: Secure user authentication.
    *   **Firestore**: Real-time data synchronization.
    *   **Firebase Storage**: Secure document and image hosting.
    *   **Cloud Messaging**: Transaction alerts and notifications.
*   **Other Libraries**: WorkManager (background tasks), Biometrics, iText (PDF generation).

## 🛠 Installation & Setup

1.  Clone the repository: `git clone https://github.com/Raphael-lab-k/SmartSaccoApp.git`
2.  Open the project in **Android Studio**.
3.  Create a Firebase project and add your `google-services.json` to the `app/` directory.
4.  Enable Firestore, Auth (Email/Password), and Storage in your Firebase console.
5.  Build and run on an emulator or physical device (Min SDK 24).
